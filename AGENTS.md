# AGENTS.md — DentCool Landing MVP

## Contexto

Este proyecto es una landing page MVP para DentCool, orientada a captar pacientes desde Instagram Ads hacia una evaluación dental en Ñuñoa, Santiago de Chile.

La base existente es:

- `index.html`
- `agenda.html`
- `css/styles.css`
- `js/script.js`

## Objetivo principal

Convertir visitas en:

1. Reservas de evaluación dental.
2. Clics a WhatsApp.
3. Leads medibles con tracking seguro.

## Reglas de trabajo

- No rehacer toda la landing sin autorización.
- Mantener HTML, CSS y JavaScript simple.
- No dejar botones o agendas falsas en producción.
- No usar `alert()` como simulación de reserva real.
- Optimizar primero para móvil.
- Preparar el proyecto para deploy estático en Vercel.
- Dejar lista la integración con Calendly o Google Appointment Schedule.
- Mantener WhatsApp como canal de apoyo.

## Tono de marca

Profesional, cercano, claro y confiable.

Evitar promesas clínicas absolutas. Preferir lenguaje como:

- Previa evaluación.
- Según diagnóstico profesional.
- Te orientamos sobre el tratamiento más adecuado.
- Precios claros antes de comenzar.
